# Architecture decision records

Every lasting decision is recorded here, one file per decision, numbered in order. Read the ADRs for an area before changing it, and write a new ADR when you change a decision (mark the old one superseded rather than editing its decision).

Format: title, status (proposed, accepted, superseded by NNNN), context, decision, consequences. Decisions marked *needs human review* change something the technical design proposed and wait for sign-off at the next milestone gate. *Accepted (owner, date)* records the owner's sign-off at a gate and names the option chosen.
