# Architecture decision records

Every lasting decision is recorded here, one file per decision, numbered in order. Read the ADRs for an area before changing it, and write a new ADR when you change a decision (mark the old one superseded rather than editing its decision).

Format: title, status (proposed, accepted, superseded by NNNN), context, decision, consequences. Decisions marked *needs human review* change something the technical design proposed and wait for sign-off at the next milestone gate. *Accepted (owner, date)* records the owner's sign-off at a gate and names the option chosen.

**The owner's standing rule (2026-11-05).** The owner decided the open gates on 2026-11-05. For every choice after them, the owner set a rule in place of asking: go with the most open-source approach, the safest approach, the industry standard, and the recommendation of the work that meets the choice. A choice this rule settles is built, not left waiting. Its ADR names the options considered and why the rule picks one. The ADR carries the status *Accepted (owner's rule of 2026-11-05)*. A decision the owner made by name that day carries *Accepted (owner, 2026-11-05)* with the option chosen.
