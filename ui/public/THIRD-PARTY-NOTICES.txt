== Open CASCADE Technology ==

The Partsmith web app uses Open CASCADE Technology (OCCT) 7.9.3, https://dev.opencascade.org, copyright OPEN CASCADE SAS and the OCCT contributors. OCCT is free software under the GNU Lesser General Public License version 2.1 with the Open CASCADE exception version 1.0. It includes code from the other projects listed after it, under their own notices. All these texts are below.

OCCT is linked statically into the app's geometry core, core/partsmith_core.wasm. It is the unmodified source of the tag V7_9_3 of https://github.com/Open-Cascade-SAS/OCCT, built as static WebAssembly libraries by the script scripts/build-occt.sh in the Partsmith source, which lists the toolkits and options used.

You may modify OCCT and use your version with Partsmith. Each deployment of this site is built from one commit of https://github.com/blai30/partsmith: production from its main branch, a preview from the head commit of its pull request; that commit holds every script, tool version and lock file the build uses. To relink: put your OCCT source in <work>/src, run OCCT_WORK_DIR=<work> scripts/build-occt.sh wasm <prefix> with the Emscripten SDK of scripts/emsdk-version.sh active, and build the core with OCCT_ROOT_WASM32_UNKNOWN_EMSCRIPTEN=<prefix> and then the app as README.md describes (scripts/build-wasm.sh, then pnpm -C ui build). The exact commands are the steps of the core-wasm and web jobs in .github/workflows/ci.yml at that commit.
